# Loom

**Loom = Beacon 的升级品牌线（产品 v2）**，不是「loom-v2」旁支名。

| 轨 | CLI | Skills |
|----|-----|--------|
| 生产 Beacon | `beacon` | `$beacon-goal` / `beacon-*` |
| 进化 Loom | **`loom`** | `$loom-goal` / `loom-*` |

```bash
loom slug list --json
loom skill-score --json
```

Slug 身份可暂留 `beacon-v2-*`；显示名用 Loom（见 `slug-alias.md`）。
