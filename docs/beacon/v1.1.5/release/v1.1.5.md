# Release: v1.1.5

## Summary
v1.1.5 完成 Beacon 的人机协作分层与 runtime 发布升级：
- human primary surface
- machine secondary surface (`.machine`)
- memory 4-layer architecture
- doctor destructive repair scope

## Scope
- runtime release line = `v1.1.5`
- `.machine` / human primary surface / eval-lab skeleton 已落地
- release / gate / delivery evidence 已闭环
- `eval-lab` 仍然只实现最小骨架，不进入整仓自治

## Delivery Readiness

v1.1.5 当前应视为：

- implemented
- release-ready
- destructive-repair capable

原因：

1. materials 已形成完整主链；
2. runtime 已切换到 `v1.1.5`；
3. delivery / gate 已形成 v1.1.5 闭环；
4. `doctor repair-package` 可把旧包迁到 `.machine` 分层结构。

## Safe Implementation Position

v1.1.5 的实现目标是：

- 重构 Beacon 的 human / machine / runtime 三面边界
- 调整 machine artifact 的正式归位路径
- 收口人类主阅读面
- 强化 doctor 作为修复器的职责

v1.1.5 的实现不应变成：

- runtime orchestration 扩张
- 新 runner 平台化
- 全仓自动研究
- agent lab 式能力膨胀
