# Beacon v1.0.3 Release Notes

Date: 2026-03-05  
Version: v1.0.3  
Type: Hotfix Iteration 1 (workflow closure + memory loop hardening)

## Highlights

- Workflow state machine now includes `gate` (7-stage closure).
- `completed` is now strictly gated by `closure_complete && gate_pass`.
- Fixed false-closure risk in `workflow --auto --skip`.
- Added interactive Workflow HUD + next-step confirmation loop.
- Implemented real timeout handling (`--confirm-timeout`, `--on-timeout`).
- `resume` contract unified:
  - `beacon resume <run_id>`
  - `beacon resume continue <run_id>|--run-id <run_id>`
- `release check` now validates real artifacts:
  - `.beacon/auto-test-status.json`
  - `.beacon/gate-report.json`
  - `.beacon/evidence-manifest.json`
  - coverage artifact
- `gate --mode dry-run` is non-blocking (exit 0).

## Memory v1

- Introduced canonical `.beacon/memory/memory-v1.json`.
- Added revision semantics and metadata fields:
  - `status`, `content_hash`, `reason_codes`
  - `revision_of`, `superseded_by`
- Added layered recall/search contract:
  - `--mode keyword|semantic|hybrid`
  - `--layer index|timeline|detail`
  - `--ids`
- Feedback pipeline upgraded to `extract/apply/sync` with artifact outputs.
- Lifecycle recovery supports attempts:
  - `attempt_id`, `attempt_seq`, `supersedes_event_id`
