# Beacon v1.1.0 子命令功能说明蓝图

> 目标：给出「所有子命令」的核心能力、触发边界与路由可达性，作为产品说明与协作对齐基线。

## 1. 统计口径

- 子命令总数：**39**（来源：`beacon/prefixed.py::SUPPORTED_SUBCOMMANDS`）
- Prompt/Ask 直达意图：**30**（来源：`beacon/utils/intent_router.py::SUPPORTED_INTENTS`，不含 `outside-boundary`）
- 需显式命令：**9**（`ask`、`brainstorm`、`debug`、`evolution-summary`、`kano`、`moscow`、`prompt`、`ralph-bridge`、`work`）

## 2. 全局边界（统一）

Beacon 主职责是 **产品工作流治理与证据闭环**，不是通用工程执行器。

- **In scope（推荐）**：需求澄清、用户故事、PRD、测试矩阵、进度、门禁、发布检查、记忆闭环、协作编排
- **Out of scope（默认阻断）**：直接写业务代码、线上故障修复、数据库迁移、生产部署、K8s/Terraform 上线脚本等

## 4. 使用建议

1. 需要稳定触发时优先用显式命令：`beacon <subcommand> ...`
2. 使用自然语言时优先：`beacon ask "..." --plan-only --json`
3. 高风险请求（混合边界/低置信度）先拆分，再执行
4. 涉及工程实现或生产部署时，请转交工程执行链（非 Beacon 边界）
