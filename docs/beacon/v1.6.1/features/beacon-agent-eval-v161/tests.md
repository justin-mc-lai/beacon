- TC-AE-001..010、017..018、027 在 Phase A–F 实现前允许 tasks 台账标注 `BLOCKED:Phase-*`；**不得**用裸 `integration` 或 `可选` 作为验证列。
- Agent Eval scorecard 为 **runtime evidence**；formal feature QA/release 仍由 `beacon-eval-qa` / `beacon-eval-release` 裁决。
- Markdown 表内 command **禁止**使用未转义的 `|` pipe；复杂断言用 `.beacon/qa-tmp` 重定向。
