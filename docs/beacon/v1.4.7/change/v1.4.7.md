## Feature Packages
- `beacon-v1.4.7-meta-protocol-and-horizontal-engineering-support-surfaces`: freeze the first accepted slice for Beacon meta-protocol convergence, host-native routing, first-wave horizontal engineering support skills, and lightweight human-readable references.
- `beacon-v1.4.7-bounded-automation-closure-state-kernel`: freeze the bounded automation runtime kernel for closure-state envelope, repeated QA/implement repair routing, and queue-safety primitives without promising full autonomous closure-loop behavior.
- `beacon-v1.4.7-automation-support-review-truth-refreeze-and-promotion-contract`: freeze the second automation runtime slice for support-review routing, truth-refreeze barriers, scenario-discovery split, and promotion-proof hooks without granting automation truth-moving authority.
- `beacon-v1.4.7-change-refreeze-one-shot-requirement-closure`: implement and verify a human-facing one-shot refreeze route across change, PRD, user-story, test-case, requirement clarity, and freeze.
- `beacon-v1.4.7-change-refreeze-human-skill-stable-route`: implement and verify a stable `beacon-change-refreeze` human skill route that delegates to `beacon change ... --refreeze-chain` without creating a new stage, truth source, or gate.
- `beacon-v1.4.7-deep-lightweight-lineage-projection-contract`: implement and verify trace-on-promotion deep lineage projection that keeps discovery lightweight and defers canonical trace to adoption/promotion surfaces.
