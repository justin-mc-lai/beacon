# Beacon v1.3.8 Release Note

## Release Type

- delivery release line: `v1.3.8`
- runtime release line: `v1.3.8`
- canonical docs line: `docs/beacon/v1.3.8/`

`v1.3.8` closes Beacon's truth lifecycle governance line and promotes that package to the current runtime kernel. This release packages the executable diagram truth layer, post-freeze host prompt trace closure, and archive governance so truth admission, execution, and retirement stay on one canonical version package.

## What Ships In v1.3.8

1. PRD executable diagram truth layer
   - PRD now carries branch-flow, state-machine, decision-priority, and state-axis truth that feeds requirement clarity and implementation planning.
   - implementation plan projection preserves diagram review gates instead of flattening complex behavior into prose-only task lists.

2. Post-freeze team / Ralph host prompt trace
   - post-freeze implement orchestration now persists host prompt input, sequencing, and runtime lane traceability.
   - team / Ralph execution surfaces keep version-bound prompt evidence instead of leaving host prompt flow implicit.

3. Archive governance and historical requirement isolation
   - Beacon now exposes `beacon archive plan/apply/status/explain` as a support command with `beacon:beacon-archive` routing.
   - archive metadata isolates historical truth from the current active delivery plane while keeping it traceable and learnable.

4. Version-level truth lifecycle closure
   - the umbrella `truth lifecycle governance` line now closes truth admission, execution, and retirement in one released docs package.
   - version-level change docs, coverage evidence, release memory, and runtime projection transaction metadata are aligned to the same `v1.3.8` package.

## Release Boundary

- In scope:
  - `docs/beacon/v1.3.8/` requirement, execution, QA, change, and release materials
  - executable diagram truth propagation into planning and gate surfaces
  - post-freeze host prompt trace persistence for implement/team flows
  - archive support command, archive skill routing, and historical truth isolation
  - repository runtime default promotion to `v1.3.8`
- Out of scope:
  - turning archive into a new lifecycle stage
  - letting archived truth re-enter current implement / qa / release by default
