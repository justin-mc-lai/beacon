# 低保真线框页：恢复诊断

**平台**: `Web, PC`
**优先级**: `P2`

## 页面意图
- 目标读者：负责恢复上下文的人
- 页面任务：解释 degraded / rebuild / doctor，明确 truth 仍来自 docs/beacon 与 .beacon。
- 先回答的问题：当前是 degraded、rebuild 还是 doctor 场景。
- 先回答的问题：真相是否仍然回到 docs/beacon 与 .beacon。
- 先回答的问题：用户该做哪一步恢复，而不是读一堆诊断术语。

## 布局草图
```text
+----------------------------------------------------------------------------------+
| 顶栏：返回项目详情 | 恢复诊断 | 当前环境状态                                      |
+----------------------------------------------------------------------------------+
| truth 来源说明                                                                    |
| - 正式真相来自 docs/beacon + .beacon                                              |
| - 当前页只解释恢复路径，不改写 requirement truth                                   |
+----------------------------------------------------------------------------------+
| 诊断卡： degraded | rebuild | doctor                                              |
| - 当前命中的诊断类型                                                               |
| - 推荐动作与触发条件                                                               |
+----------------------------------------------------------------------------------+
| 恢复步骤                                      | 风险提示                           |
| 1. 校验上下文                                 | - 不要把投影层当真相              |
| 2. 执行 doctor / rebuild                      | - 误修复会导致 drift              |
| 3. 回到项目页验证                             | - 先验证再 freeze                 |
+----------------------------------------------------------------------------------+
```

## 版面拆解
- `truth 来源说明`: 放在首屏，承载该页完成核心判断所需的最小信息块。
- `degraded / rebuild / doctor 诊断卡`: 放在主体区，集中暴露异常与介入信号，避免风险被正常信息淹没。
- `恢复步骤`: 放在主体区，集中暴露异常与介入信号，避免风险被正常信息淹没。
- `风险提示`: 放在收口区，集中暴露异常与介入信号，避免风险被正常信息淹没。

## 信息优先级
- 第一优先看 `truth 来源说明`，因为页面必须先完成第一轮判断。
- 第二优先看 `degraded / rebuild / doctor 诊断卡`，用于补足判断依据并决定是否下钻。
- 最后收口到 `风险提示`，让用户在读完后知道下一步动作。
- 审阅原则：先讲 truth 来源，再给诊断卡和恢复步骤。
- 审阅原则：风险提示要比操作细节更醒目，避免误用恢复动作。

## 关键交互
- `返回项目详情`: 通过 点击返回 回到 `project-detail`，用于撤销下钻并保留上层判断。
- `前往运行中心`: 通过 点击运行态关联 下钻到 `runtime-center`，只在当前页信息不足时继续展开。

## 状态切换与兜底
- `健康但预警`: 当前系统可用但存在恢复风险提示。
- `降级`: SQLite 或 PocketBase 缺失，但 truth 仍可从文档恢复。
- `建议重建`: 投影层需要重建。
- `建议 doctor`: 推荐执行 doctor 修复上下文。
- `加载中`: 诊断结果仍在采集。 加载态只保留骨架结构，避免造成页面重新排版。
- `错误`: 诊断页本身无法完成聚合。 页面要优先给出回退或恢复入口，而不是只报错。

## 审阅边界
- 诊断页解释机器状态，但不能反客为主替代 requirement truth。
- 这页只冻结信息结构、交互收口和状态兜底，不表达高保真视觉或最终实现细节。
