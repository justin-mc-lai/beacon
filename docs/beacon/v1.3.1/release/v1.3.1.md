# Beacon v1.3.1 发布线说明

**状态**：规划线  
**日期**：2026-04-12

## 目的

记录 `v1.3.1` 作为下一条规划线的目标：

- 收窄人类主心智面
- 保留机器内部协作自由度
- 让旧项目物料升级更轻

## 当前结论

`v1.3.1` 当前不是新的 runtime release line。

它首先是一条规划线，用来明确：

1. 人类主闭环只保留六段
2. `brainstorm` 嵌入 `prd -> user-story`
3. `implement` / `qa` 对人类保持单入口
4. learning / auto research 在 QA 中围绕冻结故事做覆盖增强
5. 旧文档物料可按版本一键更新
6. freeze 前的需求审核阻塞规则被明确
7. implement 前的 deterministic implementation contract 被明确
8. 极简 CLI 成为正式探索目标

## 提升前退出标准

1. 人类主文档明确给出六段闭环。
2. `brainstorm` 与 `prd/user-story` 的关系被正式定义。
3. `boundaries.md` 明确人类主命令、辅助命令、隐藏机器命令与 freeze/implement 阻塞边界。
4. deterministic implementation contract 的最小字段被定义。
5. `implement` / `qa` 的人类入口与机器 lane 分层被锁定。
6. 旧项目 machine materials 的按版本同步契约被明确。
7. 极简 CLI 不削弱正式交付闭环。
