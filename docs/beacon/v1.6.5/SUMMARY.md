# Beacon v1.6.5 - OSS Borrow Hardening

## Scope

v1.6.5 delivers the accepted `treehouse` and `loop-engineering` lessons as six governed phases:

- Workspace pool and durable lease semantics
- Loop readiness audit score
- Machine-readable loop pattern registry
- Cross-version protected path denylist
- Loop token budget ledger and kill switch
- Loop failure-mode catalog
