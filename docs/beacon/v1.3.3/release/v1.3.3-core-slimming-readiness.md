# Beacon v1.3.3 Release Readiness

**Version**: `v1.3.3`  
**Theme**: `core slimming + external skill demotion + minimal HUD`  
**Date**: `2026-04-16`

## Release objective

确保 Beacon 在不扩张人类心智负担的前提下完成以下交付：

- 核心主面继续保持 `6+3`
- external skill/runner 进入 compatibility plane
- HUD 在 Codex / Claude 上按极简契约稳定展示
- requirement → implement → qa → review → accept 路径可闭环

## Required closure checklist

1. Formal package closure（`SUMMARY / execution / prd / user-story / qa/test-cases / release / source-architecture`）
2. Implement writeback complete（plan、technical archive、summary）
3. QA evidence available and traceable（AC/TC coverage + scorecard）
4. Review quality completed
5. Review accept completed
6. Release gate check passed

## Current governance note

- 本版本线明确区分：
  - **current-feature closure readiness**
  - **version-line package closure readiness**
- 两者必须分别可见，不允许将任一状态静默吞并。

## Go/No-Go criteria

Go:

- `beacon help` 给出 release-check 或明确的非阻塞下一步
- `beacon review quality` 无 critical issue
- `beacon review accept` 返回 accepted
- `beacon gate check release` 通过

No-Go:

- formal package closure 缺失
- QA coverage/scorecard 未收敛
- artifact writeback obligations 未闭合
- release gate 关键项失败
