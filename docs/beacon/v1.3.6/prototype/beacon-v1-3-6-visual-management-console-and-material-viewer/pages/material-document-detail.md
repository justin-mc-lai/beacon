# 低保真线框页：物料文档详情

**平台**: `Web, PC`
**优先级**: `P2`

## 页面意图
- 目标读者：需要持续阅读单篇物料的审阅者
- 页面任务：冻结文档阅读状态，包括来源路径、版本切换和同类文档切换。
- 先回答的问题：当前读的是哪一版、哪一类、哪个 feature 的文档。
- 先回答的问题：如何在同类文档之间切换，而不丢失阅读上下文。
- 先回答的问题：当来源缺失时，用户如何回退到上层查看器。

## 布局草图
```text
+-----------------------------------------------------------------------------------+
| 顶栏：返回物料查看器 | 文档详情 | 当前版本 / 类型 / feature                        |
+-----------------------------------------------------------------------------------+
| 文档头部信息                                                                       |
| 标题 | 更新时间 | 来源版本 | 文档类型                                              |
+-----------------------------------------------------------------------------------+
| 面包屑： version / document type / feature / current document                      |
+-----------------------------------------------------------------------------------+
| Markdown 正文区                                                                    |
| # 文档标题                                                                         |
| 段落 / 列表 / 冻结说明 / requirement 内容预览                                     |
+-----------------------------------------------------------------------------------+
| 同类文档切换                               | 来源路径 / 只读说明                    |
| - 上一篇 / 下一篇                          | - docs/beacon/...                     |
| - 同版本相邻文档                           | - 不提供网页内编辑                     |
+-----------------------------------------------------------------------------------+
```

## 版面拆解
- `文档头部信息`: 放在首屏，先建立上下文，让人快速判断当前局面。
- `版本 / 类型 / feature 面包屑`: 放在主体区，承载该页完成核心判断所需的最小信息块。
- `Markdown 正文区`: 放在主体区，稳定承载只读内容，避免把注意力打散到无关控件。
- `同类文档切换`: 放在主体区，稳定承载只读内容，避免把注意力打散到无关控件。
- `来源路径与只读说明`: 放在收口区，补充可信来源与边界说明，但不应压过主体内容。

## 信息优先级
- 第一优先看 `文档头部信息`，因为页面必须先完成第一轮判断。
- 第二优先看 `版本 / 类型 / feature 面包屑`，用于补足判断依据并决定是否下钻。
- 最后收口到 `来源路径与只读说明`，让用户在读完后知道下一步动作。
- 审阅原则：面包屑和文档头部先稳定上下文，再展开正文。
- 审阅原则：正文区必须占据视觉主体，切换控件退居辅助位置。

## 关键交互
- `返回物料查看器`: 通过 点击返回 回到 `material-viewer`，用于撤销下钻并保留上层判断。
- `切换同版本文档`: 通过 点击侧栏文档 留在本页切换阅读对象，避免跳出当前上下文。

## 状态切换与兜底
- `文档已打开`: 显示文档正文与来源路径。
- `切换同类文档`: 在阅读区切换相邻文档。
- `切换版本`: 切换到同类型的其他版本文档。
- `来源缺失`: 文档不存在或来源路径不可达。 页面要优先给出回退或恢复入口，而不是只报错。

## 审阅边界
- 详情阅读页不展示机器合同或 requirement 文件路径原文。
- 这页只冻结信息结构、交互收口和状态兜底，不表达高保真视觉或最终实现细节。
