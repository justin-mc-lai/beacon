# 低保真线框页：项目物料查看器

**平台**: `Web, PC`
**优先级**: `P1`

## 页面意图
- 目标读者：查看 Beacon 物料的人
- 页面任务：按 version -> document type -> feature 提供只读 Markdown 浏览。
- 先回答的问题：当前要看哪个版本、哪类文档、哪个 feature。
- 先回答的问题：Markdown 物料是否存在，并能否稳定切换浏览。
- 先回答的问题：这只是只读消费面，真相仍在本地 docs/beacon 与 .beacon。

## 布局草图
```text
+-----------------------------------------------------------------------------------+
| 顶栏：返回项目详情 | 项目物料查看器 | 当前项目 | 只读模式                         |
+-----------------------------------------------------------------------------------+
| 左侧导航                                                                           |
| 版本树            | 文档类型列表            | feature / 文档目录                  |
| v1.3.6            | prd                    | beacon-v1.3.6...md                   |
| v1.3.5            | user-story             | ...                                   |
| v1.3.4            | test-case              |                                       |
+-----------------------------------------------------------------------------------+
| 文档阅读面板                                                                       |
| - 文档标题 / 简介                                                                  |
| - Markdown 正文预览                                                                |
+-----------------------------------------------------------------------------------+
| 来源路径信息                                | 只读说明 / 版本切换                  |
| - docs/beacon/...                            | - 真相仍在本地文档树                 |
+-----------------------------------------------------------------------------------+
```

## 版面拆解
- `版本树`: 放在首屏，支持快速扫描和定位下一层下钻入口。
- `文档类型列表`: 放在主体区，支持快速扫描和定位下一层下钻入口。
- `feature 目录`: 放在主体区，支持快速扫描和定位下一层下钻入口。
- `文档阅读面板`: 放在主体区，稳定承载只读内容，避免把注意力打散到无关控件。
- `来源路径信息`: 放在收口区，补充可信来源与边界说明，但不应压过主体内容。

## 信息优先级
- 第一优先看 `版本树`，因为页面必须先完成第一轮判断。
- 第二优先看 `文档类型列表`，用于补足判断依据并决定是否下钻。
- 最后收口到 `来源路径信息`，让用户在读完后知道下一步动作。
- 审阅原则：左侧负责层级导航，右侧负责稳定阅读，职责不能混乱。
- 审阅原则：来源路径只做可信来源说明，不压过正文阅读体验。

## 关键交互
- `打开文档`: 通过 点击文档列表项 下钻到 `material-document-detail`，只在当前页信息不足时继续展开。
- `返回项目详情`: 通过 点击返回 回到 `project-detail`，用于撤销下钻并保留上层判断。

## 状态切换与兜底
- `可浏览`: 版本树和文档列表已加载。
- `文档已打开`: 右侧阅读区显示当前文档正文。
- `来源缺失`: 目标文档不存在或暂不可读。 页面要优先给出回退或恢复入口，而不是只报错。
- `加载中`: 文档列表或内容仍在加载。 加载态只保留骨架结构，避免造成页面重新排版。
- `空状态`: 该版本或类型下没有可读文档。 空态要说明为什么为空，以及下一步该回哪里。
- `错误`: 文档读取失败。 页面要优先给出回退或恢复入口，而不是只报错。

## 审阅边界
- 物料页必须坚持只读查看，不暴露机器索引或编辑入口。
- 这页只冻结信息结构、交互收口和状态兜底，不表达高保真视觉或最终实现细节。
