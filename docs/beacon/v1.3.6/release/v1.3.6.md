# Beacon v1.3.6 Runtime Release Note

## Release Type

- Runtime release line: `v1.3.6`
- Package version: `1.3.6`
- Docs default line: `docs/beacon/v1.3.6/`

`v1.3.6` promotes Beacon's host-native LLM architecture and delivery/read-model convergence into the current runtime truth.

## What Ships In v1.3.6

1. Requirement commands share one host-native semantic runtime
   - `prd / user-story / test-case / prototype` use the same semantic capability snapshot, mode contract, and host-response loading path.

2. Delivery commands share one delivery kernel
   - `implement / qa / release` now project one delivery contract, traceability contract, and release/readiness model.

3. Support surfaces share one read model
   - `help / status / doctor` consume the same delivery read model and surface explanation contract.

4. Public docs and skill packaging align to the runtime truth
   - root docs, packaged skills, and `docs/beacon/v1.3.6/` now describe `v1.3.6` as the active runtime line rather than a migration note.

5. Provider path is fallback-only
   - host-native Codex / Claude execution no longer treats `BEACON_LLM_API_KEY` as the default requirement.
