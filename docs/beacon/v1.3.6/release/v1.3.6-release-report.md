## 使用方式

### 在 Codex 或 Claude Code 中

**Skill 命令**:
```bash
/beacon-prd <feature>
/beacon-implement <feature>
/beacon-qa <feature>
```

**直接调用**:
```bash
beacon prd <feature>
beacon implement run <feature>
beacon qa run <feature>
```

### 模块化导入

```python
from beacon.commands.implement import adapter, git, ralph, team

# 使用子模块
adapters = adapter.discover_adapters(project_root)
commit = git.get_git_commit(project_root)
summary = ralph.build_ralph_summary(qa_payload)
valid = team.validate_team_mode("team", "codex-subagents", "")
```
