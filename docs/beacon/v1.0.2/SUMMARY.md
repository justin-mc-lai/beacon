# Beacon v1.0.2 版本摘要

## 版本目标

v1.0.2 聚焦 **QA9 + LLM 自适应测试闭环**，面向 AI Agent Skill 与 Web 项目：

1. 根据项目类型自动判定可执行 QA 方式（QA9 applicability）
2. 以 LLM + 规则生成 QA9 用例矩阵并映射自动化命令
3. 接入 Cypress / Playwright / agent-browser 混合执行策略
4. 自动回填测试结果（passed/failed/blocked、pass 数、覆盖率）
5. Gate strict 阻断假证据、假通过，形成 release 可审计闭环
