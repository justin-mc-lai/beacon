# Beacon v1.0.2 一页纸运行手册（On-call / 新成员 10 分钟上手）

> 适用：新成员、值班同学、发布负责人  
> 目标：10 分钟内跑通主流程、定位阻断、避免 Beacon 失控。  
> 口径：**文档与当前代码一致**（以 `beacon/main.py` + `beacon/prefixed.py` + `beacon/commands/*` 为准）。

---

## 0) 先记住这 4 条

1. **主流程命令**：`workflow -> test-case -> auto-test -> gate`  
2. **放行裁判**：`gate check release --mode strict --qa-policy qa9-strict`  
3. **无证据不算通过**：passed 必须有 assertion/junit/evidence  
4. **默认不 force**：`--force` 只用于应急，必须留痕

---

## 1) 10 分钟上手（最短路径）

```bash
# 1. 检查版本与状态
beacon --version
beacon status --board --version v1.0.2

# 2. 一键跑主流程（推荐）
beacon workflow start "<feature>" \
  --project . \
  --version v1.0.2 \
  --auto \
  --verify-scope qa9 \
  --verify-qa-profile web-full \
  --verify-ui-runner playwright \
  --verify-require-fresh-evidence

# 3. 严格放行检查
beacon gate check release \
  --mode strict \
  --qa-policy qa9-strict \
  --min-automation-rate 0.85
```

若被阻断：
```bash
beacon auto-test status --project . --json
beacon report --machine --version v1.0.2
```

## 4) On-call 快速排障（5 步）

1. 看总览：`beacon status --board --version v1.0.2`  
2. 看执行：`beacon auto-test status --json`  
3. 看阻断：`beacon gate check release --mode strict --qa-policy qa9-strict --json`  
4. 看报告：`beacon report --machine --version v1.0.2`  
5. 针对 reason_code 修复后重跑 verify+gate

## 5) 模块功能清单（完整口径）

> 以下为当前 CLI 已注册功能（`beacon main`），其中 prefixed (`beacon-xxx`) 以 `prefixed.py` 支持列表为准。

### A. 核心闭环
- `workflow`：端到端编排（start/continue）

- `report`：机器/人类报告

### B. 记忆与可追溯

### C. 协作与桥接

## 6) Gate 常见阻断码速查（最常用）

- `qa9_matrix_missing`：缺 QA9 矩阵
- `qa9_required_type_missing`：必需 QA 类型缺失
- `qa9_command_missing_auto_case`：自动用例无执行命令
- `assertion_count_zero_pass`：通过但断言数为 0
- `junit_missing_or_invalid`：JUnit 缺失或非法
- `execution_fingerprint_missing/mismatch`：执行指纹异常
- `evidence_replay_detected`：疑似复用旧证据
- `report_result_mismatch`：分层结果与汇总不一致

---

## 7) 人机协同防失控规则（必须执行）

1. **AI 产出建议，人类做放行决策**  
2. 任何 `na` 必须有 waiver（ticket + approved_by + expires_at）  
3. CI 默认 strict gate，不允许静默跳过  
4. 每次 blocked 都必须记录修复动作与复测结果  
5. `--force` 使用后 24h 内必须复盘
