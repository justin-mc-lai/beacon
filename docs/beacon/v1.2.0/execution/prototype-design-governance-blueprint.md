# Beacon v1.2.0 Prototype Design Governance Blueprint

This runtime line keeps prototype/design governance as a **supporting constraint**, not the product center.

## v1.2.0 rule

Prototype work must stay anchored to:

```text
PRD → user-story → QA → implementation evidence
```

## What shipped

- prototype anchoring remains part of the requirement package
- reverse-drift detection is reflected in the v1.2.0 user story / PRD / QA bundle
- release evaluation consumes prototype alignment as supporting evidence, not as a substitute for the mainline
