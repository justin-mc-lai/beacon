# Beacon v1.1.2 Release Notes

Date: 2026-03-16  
Version: v1.1.2  
Type: Feature Release (prototype lifecycle + Bootstrap default stack)

## Highlights

- Added `beacon prototype` command group:
  - `create`
  - `preview`
  - `freeze`
  - `status`
  - `list`
- Added Bootstrap-based static single-page reference prototype generation.
- Integrated optional `prototype` stage into workflow via `--with-prototype`.
- Added gate validation for prototype lifecycle artifacts:
  - `prototype_missing`
  - `prototype_not_frozen`
  - `prototype_stale`
  - `prototype_source_untraceable`
- Prompt routing now recognizes prototype intents such as `交互原型` / `可点击原型`.
- Current release line, runtime metadata, and docs were aligned to **v1.1.2**.

## Default Prototype Stack

Beacon prototype now defaults to:

- Bootstrap 5.3.x
- Bootstrap Icons
- Beacon Theme CSS
- Alpine.js 3.x
- Minimal vanilla JS

Rationale:

> Beacon 原型默认选 Bootstrap，不是因为它最潮，而是因为它最适合“静态单页、快速生成、带弹窗跳转、可冻结、可治理”的交付场景。

## Workflow Semantics

UI-focused runs can now follow:

`think -> user-story -> prd -> prototype -> test-case -> implementation -> verify -> gate`

- `prototype` is optional and enabled explicitly via `--with-prototype`
- non-UI runs continue without forcing prototype
- release/prototype gate checks enforce frozen and non-stale prototype artifacts when required
