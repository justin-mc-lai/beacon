# Beacon v1.4.12 Release Note

**Status**: released  
**Date**: 2026-05-31  
**Release Line**: v1.4.12

## Overview

v1.4.12 freezes two foundational contracts that bring deterministic structure to Beacon's truth triptych and feature discovery, eliminating glob-based drift and format inconsistency that have compounded across versions.

## What's New

### 1. Version Material File Map Contract

- Manifest-based feature discovery replaces glob scanning across all modules
- `version-features.json` serves as the canonical feature list within a version
- CLI: `beacon manifest` (show, features, add-feature, remove-feature, verify, paths, sync)
- Zero compat fallback for v1.4.12+; no `_build_legacy_manifest_from_glob`

### 2. Unified Truth Template CLI Contract

- Fixed English templates for PRD, User Story, Test Cases — no numbering, pure English section titles
- Mandatory mermaid Outline diagrams positioned before detailed sections (overview-first principle)
- `beacon truth` CLI: init, verify, show with `--lang en|zh`
- `beacon truth verify --strict` enforces format: section compliance, numbering rejection, mermaid presence, language consistency
- Old entry points (`beacon prd create`, `prd_bootstrap`) delegate to new templates for v1.4.12+

### 3. Diagram Truth Propagation

- Diagram Truth Layer numbering removed, mermaid encouraged for machine-parseable diagrams
- Propagation contract extended: US AC must declare state axis coverage, TC must declare branch coverage mapping
- Outline (mandatory) vs Diagram Truth Layer (optional) clear separation

### 4. Implementation

- New modules: `beacon/utils/manifest.py`, `beacon/commands/manifest.py`, `beacon/utils/truth_template.py`, `beacon/utils/truth_format.py`, `beacon/commands/truth.py`
- Glob consumers migrated: `material_sync._discover_features`, `material_audit._feature_names` → manifest-based for v1.4.12+
- Gate integration: `build_requirement_package_gate` checks `truth_format_non_compliant`
- Skill reference file: `skills/beacon/references/truth-format-spec.md`

## Frozen Feature Packages

1. **version-material-file-map-contract** — Manifest as single source of truth for feature discovery
2. **unified-truth-template-cli-contract** — Fixed English templates with mandatory Outline mermaid diagrams

## QA Acceptance

- 15/15 Acceptance Criteria verified
- 26/26 unit tests passing
- Full CLI verification: manifest verify, truth verify (strict mode)
- Frozen state: 2 features, baseline hashes consistent

## Breaking Changes

- v1.4.11 and earlier glob-based discovery is not supported for v1.4.12+ code paths
- Truth documents must follow fixed English templates (no numbering prefixes allowed)
- Old format truth documents must go through `beacon change --refreeze-chain` to upgrade
- `beacon doctor migrate-truth-format` command intentionally omitted; use refreeze path

## Migration Path

1. Run `beacon manifest sync --version v1.4.12` to initialize from existing files
2. Run `beacon manifest verify --version v1.4.12 --strict` to validate consistency
3. For each feature, run `beacon truth verify --feature <slug> --version v1.4.12 --strict` to validate format
4. Upgrade old truth formats through `beacon change --refreeze-chain`
