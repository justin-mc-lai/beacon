# Beacon v1.4.9 Change Document

**Version**: `v1.4.9`  
**Status**: `requirement_frozen`  
**Updated**: `2026-05-23`

## Scope

- feature packages included: 3
- this version change summary is a human index over the governed feature change/refreeze packages
- implementation, QA, and release are not executed by this document

## Feature Packages

- `ui-ux-externalization-prototype-adapter-and-version-visualization-contract`: Beacon UI/UX execution ownership is externalized to `ui-ux-dev`; Beacon keeps only design-result adapter governance and version visualization truth bindings.
- `real-project-qa-evidence-binding-and-markdown-matrix-fail-closed`: Real project QA closure is hardened through implementation evidence writeback, Markdown QA matrix compilation, runner profile governance, blocker taxonomy, and BMTOP regression fixture.
- `read-only-support-research-write-topology-gate-contract`: Read-only support research writes are frozen behind a topology gate: ordinary support reviews upsert `research/<feature>.md`; `beacon-deep` writes detailed artifacts to `deep/<feature>/`; `beacon-learn` writes to `learning/<feature>.md` or transaction; research only indexes deep and learning influence.

## Added

- v1.4.9 requirement package for read-only support research write topology gate.
- AC-008 pre-write topology gate requirement: no support output persistence until `version`, `feature`, and support surface class resolve to a governed target.

## Removed / Reduced

- `docs/brainstorms/` is no longer a fallback target for explicit Beacon version+feature read-only support analysis.
- `beacon-deep` and `beacon-learn` are excluded from ordinary research body writeback; research stores only index summaries for those surfaces.

## Fixed

- Requirement clarification now has one governed feature research convergence point for ordinary support review surfaces.
- Repeated same-version clarification must update rounds or supersede owned sections instead of creating duplicate sibling files.
- Cross-version clarification must carry lineage instead of overwriting prior-version research context.
