## Cleanup Rule

- `docs/analysis/` 中非对比类、非长期借鉴类的临时分析稿一律不保留。
- `docs/brainstorms/` 中仅保留已进入正式真相链所需的 frozen materials；未进入正式真相链的对比/借鉴类草稿，若仍有长期参考价值，则迁入本目录；其余清理。
