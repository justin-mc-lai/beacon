# Release: v1.3.3

**Version**: `v1.3.3`  
**Date**: `2026-04-17`  
**Status**: `current runtime release line`

---

## Release Position

- `v1.3.3` 当前是 Beacon 正式 runtime release line。
- 包版本真相、runtime version、默认 docs line 当前都对齐到 `v1.3.3`。
- 后续 `v1.3.5 / v1.3.6` 可以继续作为 planning / migration line 并行存在，但不覆盖 `v1.3.3` 的当前发布真相。

## Theme

Core slimming, host-native priority, and external-skill demotion.

这条线的重点不是继续扩张执行面，而是把 Beacon 收回到更轻、更稳定、更清晰的主路径：

```text
prd
→ user-story
→ test-case
→ implement
→ qa
→ release
```

辅助面保持为：

```text
help
status
doctor
```

## Why This Line Exists

`v1.3.2` 已经把 implement 三模式、浏览器 QA、host-native subagent/team 等执行能力收紧过一轮。

`v1.3.3` 的价值不再是“继续加更多命令”，而是：

- 把主教学路径重新固定回 `6+3`
- 把 `omx / omc / gstack / skill / profile / orchestrate / bridge` 退到 compatibility plane
- 让宿主原生能力优先于重型兼容链路
- 让 `qa` 与默认主叙事不再隐式耦合外部 orchestration
- 保留正式 requirement truth、contract gate 与 evidence system，但从主路径中拿掉多余心智负担

## Scope

### Included in v1.3.3

- core vs compatibility 分层
- README / root skill / packaged skill / help 叙事收口
- `qa` 默认路径去隐式 external orchestration
- minimal HUD 场景与固定 HUD 契约
- memory / friction evolution toolkit 作为 optional analysis plane
- 真实项目所需的 contract / evidence / gate 继续保留

### Explicitly not the point of this line

- 继续扩大公开命令面
- 把外部兼容执行器重新拉回 core narrative
- 删除所有 legacy 兼容代码
- 重写 `v1.3.2` 已验收的执行闭环

## Current Runtime Facts

这些事实当前已成为仓库中 `v1.3.3` release line 的组成部分：

- `v1.3.3` 是 `beacon/__init__.py`、`pyproject.toml`、`beacon/version-truth.json` 对齐后的当前 runtime release line
- 根 README、根 `SKILL.md` 与 `skills/beacon/` 统一对齐 `v1.3.3`
- Beacon 默认人类主流程固定为 `prd -> user-story -> test-case -> implement -> qa -> release`
- 默认辅助面固定为 `help / status / doctor`
- 外部 runner / profile / orchestrate / bridge 退到 compatibility plane
- `minimal_hud`、固定 HUD 注入与 support surface 的轻量叙事成为 `v1.3.3` 的正式组成部分
- memory/friction 进化能力保留，但不扩张主 `6+3` 心智模型
