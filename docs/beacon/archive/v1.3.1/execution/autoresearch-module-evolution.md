# Beacon v1.3.1 Autoresearch Module Evolution

`v1.3.1` 对 autoresearch 的演进不是“更显眼”，而是“更内嵌”。

## Evolution

- `v1.3.0`: autoresearch 已存在，但更多被理解成独立能力
- `v1.3.1`: autoresearch 明确退到 `qa` 背后的 machine lane

## Current rule

- human primary loop does not expand
- machine lanes remain allowed
- release truth must still回到正式 `qa` / `gate` / `change` artifacts
