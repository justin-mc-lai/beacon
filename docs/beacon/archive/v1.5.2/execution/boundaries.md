# Execution Boundaries v1.5.2

## Canonical Truth

`features/<slug>/{truth,tests,tasks,evidence}.md` is the normal canonical truth package.

## Required Resolver

All normal truth reads go through truth-map resolver before reading package files.

## Legacy Boundary

Legacy PRD/user-story/test-case files are not normal truth. They are generated or absorbed artifacts only.

## JSON Boundary

JSON projections are optional evidence and diagnostics. They are not required twins for Markdown truth.
