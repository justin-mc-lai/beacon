# Beacon v1.0.2 发布版本一致性记录

Date: 2026-03-04

## 背景

在 v1.0.2 发布核查中发现两处一致性缺口：

1. `pyproject.toml` 的 `project.version` 仍为 `1.0.1`，与代码/文档/SKILL 的 `v1.0.2` 不一致。
2. `SUPPORTED_SUBCOMMANDS` 包含 `persona`，但 `pyproject.toml` 缺少 `beacon-persona` 脚本入口，安装后无法直接使用 `beacon-persona`。

## 本次修复

### 1) 包版本对齐

- 文件：`pyproject.toml`
- 变更：`version = "1.0.1"` → `version = "1.0.2"`

### 2) Prefixed 命令入口补齐

- 文件：`pyproject.toml`
- 变更：新增 `beacon-persona = "beacon.prefixed:main"`

### 3) 增加持续一致性防回归测试

- 新增文件：`tests/test_release_version_consistency.py`
- 覆盖检查：
  - `pyproject.toml` 版本必须与 `beacon.__version__` 一致
  - `SUPPORTED_SUBCOMMANDS` 与 `pyproject.toml` 中 `beacon-*` 脚本映射必须双向一致

## 验证记录

执行命令：

```bash
python3 -m pytest -q tests/test_release_version_consistency.py
python3 -m pytest -q
```

期望结果：

- 版本一致性测试通过
- 全量测试通过（含新增一致性测试）

## 结论

v1.0.2 的“代码版本 / 打包版本 / 命令入口”一致性已补齐，并通过测试固化为发布前置约束。
