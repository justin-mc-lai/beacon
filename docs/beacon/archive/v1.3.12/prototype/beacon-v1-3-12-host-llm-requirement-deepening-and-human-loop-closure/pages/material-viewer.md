# 页面：项目物料查看器

**平台**: `Web, PC`
**优先级**: `P1`

## 页面文案
标题：项目物料查看器
副标题：当前要看哪个版本、哪类文档、哪个 feature。
主动作：打开文档, 返回项目详情

## 页面结构
版本树
文档类型列表
feature 目录

## 页面线框
```text
+-----------------------------------------------------------------------------------+
| 顶栏：返回项目详情 | 项目物料查看器 | 当前项目 | 只读模式 |
+-----------------------------------------------------------------------------------+
| 左侧导航 |
| 版本树 | 文档类型列表 | feature / 文档目录 |
| v1.3.6 | prd | beacon-v1.3.6...md |
| v1.3.5 | user-story | ... |
| v1.3.4 | test-case | |
+-----------------------------------------------------------------------------------+
| 文档阅读面板 |
| - 文档标题 / 简介 |
| - Markdown 正文预览 |
+-----------------------------------------------------------------------------------+
| 来源路径信息 | 只读说明 / 版本切换 |
| - docs/beacon/... | - 真相仍在本地文档树 |
+-----------------------------------------------------------------------------------+
```

## 页面状态
可浏览：版本树和文档列表已加载。
文档已打开：右侧阅读区显示当前文档正文。
来源缺失：目标文档不存在或暂不可读。
加载中：文档列表或内容仍在加载。
空状态：该版本或类型下没有可读文档。
错误：文档读取失败。

## 页面跳转
打开文档 -> `material-document-detail`
返回项目详情 -> `project-detail`
