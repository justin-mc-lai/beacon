### 2. agents robustness and host runtime compatibility

已交付结果：

- Beacon 把 agents 健壮性正式提升为 requirement truth，而不是只靠 implement 内部约定。
- Codex / Claude Code 的 host runtime 差异被纳入兼容治理与运行前检查。
- 对 help、review、release 等旧路径的兼容问题完成修复与回归。

关键证据：

- `docs/beacon/archive/v1.3.9/prd/beacon-v1.3.9-agents-robustness-and-host-runtime-compatibility.md`
- `docs/beacon/archive/v1.3.9/execution/qa-acceptance-beacon-v1.3.9-agents-robustness-and-host-runtime-compatibility.md`

### 3. runtime skill admission and host-validated third-party skill compatibility

已交付结果：

- Beacon 新增 runtime skill admission 子线，用于接入前校验第三方 skill 是否满足 host runtime 的运行条件。
- 保持 Beacon 不替代原生 skill create，而是在“准入、兼容、验证、路由”层做统一治理。
- 为 `beacon implement --skill` 这类未来扩展入口打下兼容基础。

关键证据：

- `docs/beacon/archive/v1.3.9/prd/beacon-v1.3.9-runtime-skill-admission-and-host-validated-third-party-skill-compatibility.md`
- `docs/beacon/archive/v1.3.9/execution/qa-acceptance-beacon-v1.3.9-runtime-skill-admission-and-host-validated-third-party-skill-compatibility.md`

### 4. beacon-friction-intake and sqlite governance queue

已交付结果：

- 新的主入口为 `beacon-friction-intake`，替代旧 `memory-friction-evolution` 作为长期推荐语义。
- 支持 `scan` 与 `capture` 两种模式，分别覆盖 Beacon 源码项目自动扫描与目标开发项目人工录入。
- 两种来源统一进入全局 sqlite friction queue，支持状态流转、恢复、重放与显式 requirement 接受。
- 默认只进治理队列，不自动写 requirement truth，保护冻结需求面。

关键证据：

- `docs/beacon/archive/v1.3.9/execution/qa-acceptance-beacon-v1.3.9-beacon-friction-intake-and-sqlite-governance-queue.md`
- `docs/beacon/archive/v1.3.9/.machine/qa/beacon-v1.3.9-beacon-friction-intake-and-sqlite-governance-queue.ac-test-matrix.json`
