# 页面：项目详情

**平台**: `Web, PC, App`
**优先级**: `P0`

## 页面文案
标题：项目详情
副标题：这条版本线当前停在哪个阶段，下一步应该推进哪里。
主动作：查看运行中心, 查看恢复诊断, 查看项目物料

## 页面结构
项目头部摘要
版本与分支信息
主 PRD 与并行 PRD

## 页面线框
```text
+-----------------------------------------------------------------------------------+
| 顶栏：返回总览 | 项目名 | 项目类型 | owner | 当前阶段 |
+-----------------------------------------------------------------------------------+
| 项目头部摘要 | 当前版本 / git / worktree |
| - 当前目标 | - version: v1.3.6 |
| - 为什么停在这里 | - branch/worktree 状态 |
+-----------------------------------------------------------------------------------+
| 主 PRD | 并行 PRD / 子线 |
| - 主线 feature | - 并行 feature A |
| - 当前承诺面 | - 并行 feature B |
+-----------------------------------------------------------------------------------+
| 需求闭环状态: prd | user-story | test-case | prototype | qa 准备度 |
+-----------------------------------------------------------------------------------+
| 最近交付 | 下一步 / 推荐动作 |
| - 最新冻结产物 | - 继续 implement / qa / review |
| - 最近一次 review 结论 | - 推荐 skill |
+-----------------------------------------------------------------------------------+
| runtime 摘要卡 | 文档查看 / 恢复诊断入口 |
| - single/team/ralph 摘要 | [查看项目物料] [查看恢复诊断] |
+-----------------------------------------------------------------------------------+
```

## 页面状态
可接力：版本、PRD、需求闭环和下一步信息完整。
需求缺口：PRD / user-story / test-case 存在缺口。
需求草稿：需求已建立但未冻结。
需求冻结：需求链与 prototype 都已冻结。
运行中：存在 single / team / ralph 运行摘要。
加载中：项目详情正在聚合。
