# 页面：功能详情

**平台**: `Web, PC`
**优先级**: `P1`

## 页面文案
标题：功能详情
副标题：当前 feature 应继续推进、等待依赖，还是进入恢复或验收路径。
主动作：进入运行详情, 进入验收面

## 页面结构
功能摘要
依赖与基线
状态与风险

```text
+-----------------------------+
| 功能摘要 |
+-----------------------------+

+-----------------------------+
| 状态与风险 |
+-----------------------------+

+-----------------------------+
```

## 页面状态
可用：功能状态完整，可判断下一步。
阻塞：功能依赖或基线存在阻塞。
待验收：功能已进入待验收状态。
错误：功能状态聚合失败，需进入恢复入口。
