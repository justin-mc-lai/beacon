# Release: v1.1.6

## Summary
v1.1.6 完成 Beacon 的实现闭环升级：
- native implement runners (`native-single` / `native-team`)
- revision lifecycle (`freeze` / `reopen`)
- machine-backed story / revision / item writeback
- help / doctor advise / scoring navigator

## Scope
- runtime release line = `v1.1.6`
- `freeze -> implement -> review accept -> reopen` 已形成正式主链
- `.machine` 中新增 user-story / execution / qa 的闭环证据
- release / gate / delivery evidence 已同步到 v1.1.6

## Delivery Readiness

v1.1.6 当前应视为：

- implemented
- release-ready
- lifecycle-closed

原因：

1. requirements / execution docs 已齐备；
2. runtime 已切换到 `v1.1.6`；
3. delivery / gate / release 证据已形成 v1.1.6 闭环；
4. help / doctor / status 已能输出阶段感知导航。

## Safe Implementation Position

v1.1.6 的实现目标是：

- 为 frozen revision 提供正式原生实现入口
- 让 story item 状态成为可回写、可验证、可验收的 machine truth
- 让 reopen 通过新 revision 保留历史而非覆盖历史
- 让操作员与 agent 不再猜命令，而由 Beacon 计算下一步

v1.1.6 的实现不应变成：

- 全栈 agent 平台扩张
- runtime/UI/K8s 平台复制
- 以 team 名义重复构建另一套外部 orchestrator
- compatibility-first 的长期旧模型兜底
