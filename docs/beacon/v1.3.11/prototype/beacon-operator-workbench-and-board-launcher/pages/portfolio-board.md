# 页面：项目组合看板

**平台**: `Web, PC`
**优先级**: `P1`

## 页面文案
标题：项目组合看板
副标题：当前应先进入阻塞 feature、待验收 feature，还是继续观察整体版本健康态。
主动作：进入执行看板, 进入功能详情

## 页面结构
状态摘要
阻塞分组
待验收分组

## 页面线框
```text
+-----------------------------+
| 状态摘要 |
+-----------------------------+
| 阻塞分组 |
+-----------------------------+
| 待验收分组 |
+-----------------------------+
| 主动作 |
+-----------------------------+
```

## 页面状态
可用：组合状态已汇总，可继续下钻。
阻塞：存在需要优先介入的阻塞 feature。
待验收：存在需要进入验收面的 feature。
加载中：组合状态仍在汇总。
错误：组合聚合失败，必须给出恢复入口。

## 页面跳转
进入执行看板 -> `execution-board`
进入功能详情 -> `feature-detail`
