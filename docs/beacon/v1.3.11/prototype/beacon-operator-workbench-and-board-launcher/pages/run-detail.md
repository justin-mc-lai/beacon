# 页面：运行详情

**平台**: `Web, PC`
**优先级**: `P1`

## 页面文案
标题：运行详情
副标题：当前运行应继续、停止、重试，还是转入 repair handoff。
主动作：进入恢复诊断, 进入验收面

## 页面结构
运行状态
阻塞原因
建议动作

## 页面线框
```text
+-----------------------------+
| 运行状态 |
+-----------------------------+
| 阻塞原因 |
+-----------------------------+
| 建议动作 |
+-----------------------------+
| 二级明细 |
+-----------------------------+
```

## 页面状态
运行中：当前运行仍在推进。
阻塞：当前运行被阻断，必须优先判断恢复动作。
待验收：当前运行等待验收。
已排队重试：当前运行等待重试。
错误：当前运行状态不一致，必须暴露恢复入口。

## 页面跳转
进入恢复诊断 -> `recovery-diagnostics`
进入验收面 -> `review-surface`
