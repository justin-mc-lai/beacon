# 页面：验收面

**平台**: `Web, PC`
**优先级**: `P1`

## 页面文案
标题：验收面
副标题：当前项应通过验收、回到修复路径，还是继续收集证据。
主动作：返回运行详情, 进入恢复诊断

## 页面结构
验收状态
差异入口
证据入口

## 页面线框
```text
+-----------------------------+
| 验收状态 |
+-----------------------------+
| 差异入口 |
+-----------------------------+
| 证据入口 |
+-----------------------------+
| 放行建议 |
+-----------------------------+
```

## 页面状态
可验收：验收证据完整，可判断是否放行。
证据不足：验收证据不足，不能放行。
阻塞：验收存在阻塞，必须进入回修路径。
错误：验收聚合失败，需优先给出恢复动作。

## 页面跳转
返回运行详情 -> `run-detail`
进入恢复诊断 -> `recovery-diagnostics`
