# 页面：执行看板

**平台**: `Web, PC`
**优先级**: `P0`

## 页面文案
标题：执行看板
副标题：当前应继续、停止、重试，还是先进入恢复入口。
主动作：进入运行详情, 进入恢复诊断, 进入功能详情

## 页面结构
状态摘要
当前阻塞
主动作

## 页面线框
```text
+-----------------------------+
| 状态摘要 |
+-----------------------------+
| 当前阻塞 |
+-----------------------------+
| 主动作 |
+-----------------------------+
| 运行分组 |
+-----------------------------+
```

## 页面状态
可用：当前运行态完整，可执行继续、停止或重试。
阻塞：存在阻塞运行，必须优先判断恢复入口。
待验收：存在待验收运行，需要进入验收面。
已排队重试：存在待重试运行，需确认是否继续。
加载中：运行状态仍在读取。
错误：运行状态读取失败，必须暴露恢复入口。

## 页面跳转
进入运行详情 -> `run-detail`
进入恢复诊断 -> `recovery-diagnostics`
进入功能详情 -> `feature-detail`
