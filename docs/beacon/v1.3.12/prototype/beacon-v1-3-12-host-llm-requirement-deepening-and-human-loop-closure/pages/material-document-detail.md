# 页面：物料文档详情

**平台**: `Web, PC`
**优先级**: `P2`

## 页面文案
标题：物料文档详情
副标题：当前读的是哪一版、哪一类、哪个 feature 的文档。
主动作：返回物料查看器, 切换同版本文档

## 页面结构
文档头部信息
版本 / 类型 / feature 面包屑
Markdown 正文区

## 页面线框
```text
+-----------------------------------------------------------------------------------+
| 顶栏：返回物料查看器 | 文档详情 | 当前版本 / 类型 / feature |
+-----------------------------------------------------------------------------------+
| 文档头部信息 |
| 标题 | 更新时间 | 来源版本 | 文档类型 |
+-----------------------------------------------------------------------------------+
| 面包屑： version / document type / feature / current document |
+-----------------------------------------------------------------------------------+
| Markdown 正文区 |
| # 文档标题 |
| 段落 / 列表 / 冻结说明 / requirement 内容预览 |
+-----------------------------------------------------------------------------------+
| 同类文档切换 | 来源路径 / 只读说明 |
| - 上一篇 / 下一篇 | - docs/beacon/... |
| - 同版本相邻文档 | - 不提供网页内编辑 |
+-----------------------------------------------------------------------------------+
```

## 页面状态
文档已打开：显示文档正文与来源路径。
切换同类文档：在阅读区切换相邻文档。
切换版本：切换到同类型的其他版本文档。
来源缺失：文档不存在或来源路径不可达。

## 页面跳转
返回物料查看器 -> `material-viewer`
切换同版本文档 -> `material-document-detail`
