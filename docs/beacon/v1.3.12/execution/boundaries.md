# Beacon v1.3.12 Boundaries

## In Scope

- host-LLM requirement deepening
- PRD-centered story discovery
- risk/state-aware test-case expansion
- supplement routing and re-freeze semantics
- help/status/board visibility for补料项

## Out of Scope

- adding a new public lifecycle stage
- bypassing frozen truth with host LLM
- treating `sync-materials` as normal requirement compile entry
- allowing delivery layers to rewrite requirement truth

## Explicit Constraints

- no new public top-level Beacon command
- no silent manual patch as normal operator path
- no delivery pass when requirement completeness is blocked
- no truth rewrite outside PRD / user-story / test-case / change
