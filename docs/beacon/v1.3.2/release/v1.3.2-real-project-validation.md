## Beacon Defects Found And Fixed During Validation

### 1. `qa run --help` hid real feature-aware options

Fix:

- public `qa run` help surface was updated to show real feature / project / version / json options

### 2. Browser runner artifact writeback broke on `/tmp` vs `/private/tmp`

Fix:

- browser runner common path handling now tolerates macOS path aliases

### 3. `qa team-run` returned non-zero even when final feature-aware QA status was `passed`

Fix:

- feature-aware QA exit code now normalizes to `0` when final status is `passed`

### 4. `help` preferred stale Ralph blocker over current authoritative feature scorecard

Fix:

- current-feature `ready_for_release` state now overrides stale Ralph repair signals in `help`

### 5. `release scorecard` / `status --board` missed authoritative feature scorecard closure

Fix:

- release aggregation now accepts authoritative feature scorecard closure for modern Beacon lines
- project profile gate fallback from feature scorecard is supported
- status semantics were clarified between current-feature closure and version-line package closure
