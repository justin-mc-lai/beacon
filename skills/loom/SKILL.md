# Loom

**Loom 就是 Beacon 的升级品牌线**（产品版本可走 v2.0.0），不是旁支产品名 `loom-v2`。

| | 生产 Beacon | 进化 Loom |
|--|-------------|-----------|
| CLI | `beacon` | **`loom`** |
| 公共 skill | `$beacon-goal` | **`$loom-goal`** |
| 前缀 | `beacon-*` | **`loom-*`** |

双装并行；安装 Loom **禁止**覆盖 `beacon`。W4 前禁止默认接管生产轨。

详见 `docs/loom/README.md`、`skills/loom/mirror-manifest.json`。
