# Loom

**Loom 就是 Beacon 的升级品牌线**，不是 loom-v2 旁支。

| | 生产 Beacon | 进化 Loom |
|--|-------------|-----------|
| CLI | `beacon` | **`loom`** |
| skill | `$beacon-goal` | **`$loom-goal`** |

双装并行；安装 Loom **禁止**覆盖 `beacon`。
