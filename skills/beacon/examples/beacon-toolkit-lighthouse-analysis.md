# Beacon Toolkit Lighthouse Example

## Goal

Generate a single-file system understanding artifact without entering the main workflow.

## Example prompts

- “Use Beacon Toolkit Lighthouse to analyze this repo and give me a one-file architecture map.”
- “Use Beacon Toolkit Lighthouse to quickly deconstruct this open-source library.”
- “Use Beacon Toolkit Lighthouse to map the gateway → service → queue → storage chain.”
- “Use Beacon Toolkit Lighthouse to break down this feature slice and its key files.”

## Expected output

- one Markdown artifact
- Mermaid diagram(s)
- key files / entry points
- confirmed vs inferred split
- next-step suggestions
